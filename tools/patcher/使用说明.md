# NBA 2K20 手游助手 · 打补丁工具使用说明

这个压缩包里**没有游戏本体**，只有助手自己的文件和打补丁工具。你需要用自己手机上的 NBA 2K20 安卓版（**v98.0.2**）APK 生成带助手的版本。

## 准备

1. 电脑装好 **Python 3.8+** 和 **Java 8+**（命令行里能运行 `python`、`java`、`keytool`）。
2. 拿到你自己的游戏 APK，任选一种：
   - 手机打开 USB 调试，电脑运行：
     ```
     adb shell pm path com.t2ksports.nba2k20and
     adb pull <上一步输出里 base.apk 的路径> 原版游戏.apk
     ```
   - 或者用手机上的「应用备份/提取 APK」类工具导出。

## 生成

在本目录运行：

```
python patch.py 原版游戏.apk
```

大约 2～3 分钟，得到 `NBA2K20-助手-v<版本>.apk`。工具会先核对游戏版本，不是 v98.0.2 会直接提示，不会生成坏包。

## 安装

- `adb install -r NBA2K20-助手-v<版本>.apk`，或把 APK 拷到手机上点开安装。
- **手机上装的是官方版**时，签名不同不能直接覆盖，要先卸载官方版——卸载会清掉本地存档，有需要先备份。
- **升级到新版本**：用同一个目录里的签名密钥（`patcher-key.p12` 和 `patcher-key.json`）再打一次补丁，就能直接覆盖安装，存档保留。这两个文件第一次运行时自动生成，请保管好，不要发给别人。
- 已经有自己签名密钥的，可以用 `--keystore 文件 --storepass 密码 [--alias 别名]` 指定。

## 使用

进游戏后屏幕左侧有一个「2K」悬浮球，点开就是助手面板。功能说明见面板里每项右边的 ⓘ，或项目主页的 README。
