# NBA 2K20 手游助手

给 **NBA 2K20 安卓版（v98.0.2）** 加一个游戏内悬浮面板：抓帽、超级抓帽、抢断、空中封盖、范围扣篮、自选扣篮动作、弹跳增强、高光慢镜头、超强人机、犯规开关、能力参数、生涯改身高……全部在游戏里随开随关。

> ⚠️ **本仓库不包含任何游戏文件。** 发布包里只有助手自己的代码和一个打补丁工具，需要用你自己的游戏 APK 生成。仅供学习研究与单机娱乐，与 2K Games / Take-Two 无关；请勿用于联网对战，使用风险自负。

## 功能一览

| 分类 | 功能 |
| --- | --- |
| 防守 | 抓帽概率（0～100%，精确到 1%）、**超级抓帽**（对手一出手球就到你手里，跳投/上篮/扣篮都算）、抢断成功率 + 断下直接抱住、空中封盖判定放宽（按手的位置算） |
| 进攻 | 三分必中、全场投篮必中、上篮/扣篮命中下限、强力隔扣、范围内按投篮即扣篮、全场热区、手感火热 |
| 扣篮 | 527 个扣篮动作的自选库：组合、权重、锁定单个动作；自动挑起跳距离合适的动作，避免「飘」过去 |
| 弹跳 | 弹跳增强（封盖、抢篮板时自动对准球的高度，不会跳过球） |
| 人机 | 超强人机（预判封盖、贴身防守、三分/冲框偏好），可设置「不针对我的必中和隔扣」 |
| 趣味 | 高光慢镜头（扣篮/盖帽/抢断）、无限接管、巨人模式 |
| 规则 | 21 种犯规/违例逐项免除 |
| 参数 | 我方/电脑 28 项能力滑条（速度、敏捷最高 ×5/×8） |
| 生涯 | 修改辉煌生涯球员身高 |

所有功能都只作用于**你操控的球员 / 你这一方**，在辉煌生涯、街头 1v1/3v3、快速比赛里都按「谁在用手柄」识别，不会认错边。

## 玩家：怎么用

1. 到 [Releases](../../releases) 下载最新的 `NBA2K20-助手-补丁工具-vX.Y.Z.zip` 并解压。
2. 准备好自己手机里的游戏 APK（v98.0.2），电脑装 Python 3.8+ 和 Java 8+。
3. 在解压目录运行 `python patch.py 原版游戏.apk`，得到 `NBA2K20-助手-vX.Y.Z.apk`，装到手机上。

详细步骤（导出 APK、签名、升级不丢存档）见压缩包里的 [使用说明](tools/patcher/使用说明.md)。

## 开发者：一起改进

欢迎提 Issue 和 Pull Request，提交前请先看 [参与贡献](CONTRIBUTING.md)。

- 构建环境和步骤：[docs/build.md](docs/build.md)
- 工作原理和已经摸清的游戏机制：[docs/notes.md](docs/notes.md)

```
src/native/   原生模块（C，单编译单元）：按符号名改 GOT/PLT 挂钩，各功能 f_*.c
src/java/     悬浮面板（纯代码绘制的界面，SharedPreferences 存设置）
gen/gen.py    设置项、统计项、扣篮动作表的唯一来源，生成 C 和 Java 两边的常量
data/         扣篮动作目录（动画 CRC、扣篮包、中文名）
build.py      构建脚本：生成表 → 编译 .so → 编译 Java/dex → 打进基础 APK → 对齐 → 签名
tools/        打补丁工具（发布用）和打包发布脚本
re/           逆向分析脚本（反汇编、查调用、校验挂钩表），需要你自己的游戏库文件
backup/       存档备份小工具（把自己手机里的存档导出到电脑）
```
